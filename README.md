# 現代兵器識別暗記アプリ (ロシア & 中国) - Material Design 3 Edition

ロシアおよび中国の現代主力戦闘機・火器・火砲・ミサイル・爆弾（全54種）の**外見（見た目）から形式名・愛称・識別ポイント・主要能力（スペック）を反復暗記**するためのWebアプリケーション。

---

## 主な特徴

1. **Material Design 3 (M3) 準拠のモダンUI**
   - Google Fonts (`Noto Sans JP`, `Roboto`, `JetBrains Mono`) と `Material Symbols` を採用。
   - タクティカルダークテーマによる洗練された視認性と3Dカードフリップアニメーション。

2. **国 × 類別ごとの柔軟な暗記学習**
   - **所属国**: 🇷🇺 ロシア / 🇨🇳 中国 / すべて
   - **類別**: ✈️ 戦闘機・航空機 / 🔫 火器・小火器 / 💥 火砲・自走砲 / 🚀 ミサイル / 💣 爆弾 / すべて
   - ワンタップで瞬時に対象を絞り込み可能。

3. **見た目重視の暗記項目**
   - **表面（問題）**: 高解像度画像 ＋ 国旗バッジ ＋ 類別バッジ
   - **裏面（回答）**:
     - 正式名称（日・英・原語）
     - NATOコードネーム / 愛称
     - **見た目の識別ポイント**（カナード翼、エアインテーク、砲塔、マズル、翼形状など）
     - **主な特徴・能力**（戦術的用途、開発背景、実戦投入例）
     - **主要スペック**（最高速度、射程、口径、主兵装）
     - **ライセンス情報**（著作権者、CCライセンス、Wikipediaリンク）

4. **反復学習と定着のための4つのモード**
   - **🗂️ 暗記カードモード**: 間隔反復（Leitnerシステム）に基づき、「もう一度 (Again)」「覚えた (Good)」「完璧 (Easy)」で習得度を管理。苦手なカードは数問後に自動で再出題。
   - **❓ 4択テストモード**: 画像を見て正しい兵器名を4択から即答する実践クイズ。正誤判定と識別ポイントの解説つき。
   - **📖 兵器図鑑モード**: 全54種類をグリッド表示。キーワード検索や詳細モーダルでじっくり予習・復習。
   - **📊 学習統計モード**: 全体・国別・類別ごとの習得進捗プログレスバーを可視化。「苦手な兵器のみ特訓」ボタン連動。

5. **ライセンスの遵守**
   - すべての画像は Wikimedia Commons（パブリックドメイン / CC BY-SA / CC BY）の利用許諾に準拠し、撮影者・ライセンス名・出典リンクをカード裏面およびモーダルに明記。

## 起動方法

### 方法1: ブラウザで直接開く
フォルダ内の `index.html` をダブルクリックするだけで、追加インストールなしですぐに利用できます。

### 方法2: ローカルサーバーで起動
```bash
python server.py
# または
npm start
```
起動すると自動的にブラウザが開きます（http://localhost:8080/index.html）。

## キーボードショートカット (暗記カードモード)

| キー | 動作 |
| :--- | :--- |
| `Space` / `Enter` | カードを裏返す（問題 ⇄ 回答） |
| `1` | もう一度（要復習・苦手） |
| `2` | 覚えた（習得中） |
| `3` | 完璧（マスター） |
| `←` / `→` | 前のカード / 次のカード |
| `R` | カードをシャッフル |
| `Esc` | 詳細モーダルを閉じる |

※スマートフォンやタブレットでの左右スワイプ操作にも対応しています。
