# 現代兵器識別暗記アプリ (ロシア & 中国) - Material Design 3 Edition

ロシアおよび中国の現代主力戦闘機・火器・火砲・ミサイル・爆弾（全54種）の外見（見た目）から形式名・愛称・識別ポイント・主要能力（スペック）を反復暗記するためのWeb/Androidアプリケーション。
Google Material Design 3 (M3) 公式ガイドライン（m3.material.io）に厳密に準拠。

---

## 主な特徴

1. **Material Design 3 (M3) 公式仕様準拠のライトUI**
   - Google Fonts (Roboto, Noto Sans JP, JetBrains Mono) と Google Material Symbols を採用。
   - M3 Dynamic Color トークン、Tonal Elevation、ピル型インジケーター付きNavigation Bar、M3 Filter Chipsを完全実装。
   - 絵文字を使用せず、公式アイコンシステムのみで統一。

2. **国と類別ごとの柔軟な暗記学習**
   - **所属国**: ロシア / 中国 / すべて
   - **類別**: 戦闘機・航空機 / 火器・小火器 / 火砲・自走砲 / ミサイル / 爆弾 / すべて
   - ワンタップで瞬時に対象を絞り込み可能。

3. **見た目重視の暗記項目**
   - **表面（問題）**: 高解像度画像、国名バッジ、類別バッジ
   - **裏面（回答）**:
     - 正式名称（日・英・原語）
     - NATOコードネーム / 愛称
     - **見た目の識別ポイント**（カナード翼、エアインテーク、砲塔、マズル、翼形状など）
     - **主な特徴・能力**（戦術的用途、開発背景、実戦投入例）
     - **主要スペック**（最高速度、射程、口径、主兵装）
     - **ライセンス情報**（著作権者、CCライセンス、Wikipediaリンク）

4. **反復学習と定着のための4つのモード**
   - **暗記カードモード**: 間隔反復（Leitnerシステム）に基づき、「もう一度 (Again)」「覚えた (Good)」「完璧 (Easy)」で習得度を管理。苦手なカードは数問後に自動で再出題。
   - **4択テストモード**: 画像を見て正しい兵器名を4択から即答する実践クイズ。正誤判定と識別ポイントの解説つき。
   - **兵器図鑑モード**: 全54種類を一覧表示。キーワード検索や詳細モーダルでじっくり予習・復習。
   - **学習統計モード**: 全体・国別・類別ごとの習得進捗プログレスバーを可視化。「要復習のみ抽出」ボタン連動。

5. **ライセンスの遵守**
   - すべての画像は Wikimedia Commons（パブリックドメイン / CC BY-SA / CC BY）の利用許諾に準拠し、撮影者・ライセンス名・出典リンクをカード裏面およびモーダルに明記。

## 起動方法

### 方法1: ブラウザで直接開く
フォルダ内の `index.html` をダブルクリックするだけで、追加インストールなしですぐに利用できます。

### 方法2: ローカルサーバーで起動
```bash
python server.py
# または
npm start
```
起動すると自動的にブラウザが開きます（http://localhost:8080/index.html）。

## キーボードショートカット (暗記カードモード)

| キー | 動作 |
| :--- | :--- |
| Space / Enter | カードを裏返す（問題と回答の切り替え） |
| 1 | もう一度（要復習・苦手） |
| 2 | 覚えた（学習中） |
| 3 | 完璧（マスター） |
| 左矢印 / 右矢印 | 前のカード / 次のカード |
| R | カードをシャッフル |
| Esc | 詳細モーダルを閉じる |

※スマートフォンやタブレットでの左右スワイプ操作にも対応しています。
